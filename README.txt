BTCUSDT Lightweight Research Bot — Prototype
============================================
1. Extract the ZIP.
2. Open index.html in Chrome or Edge on a computer with internet.
3. It uses public Binance USDⓈ-M Futures market data and needs no API keys.
4. If local-file browser restrictions prevent history fetch, the app will show an error rather than fake data.

Includes: live mark price, 24h change, recent aggregate trade flow proxy, top-20 order book, basic LONG/SHORT/WAIT research filter, recent candle chart.

Limitations: this is only a starter prototype. It does not place trades and does not yet include 12-month local history, proper fee/slippage backtesting, Telegram alerts, or fully validated liquidity sweep/BOS/CHoCH/FVG logic. The signal filter is not a proven profitable strategy. Use paper trading only while developing.
